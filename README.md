# Hauzo — Workflow Plugins for Claude CoWork

**Get it done properly.**

Hauzo is a curated marketplace of workflow plugins for [Claude CoWork](https://claude.ai). Each plugin is a multi-skill workflow system that guides you through complex, multi-step processes — the kind where you'd normally feel lost and wish you had a senior friend who'd done it before.

## Install

1. Open Claude CoWork
2. Click **Customize** (bottom-left)
3. Click **+** next to Plugins
4. Select **Add marketplace from GitHub**
5. Type `hauzo/plugins`
6. Browse and install any plugin
